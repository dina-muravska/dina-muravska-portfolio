# Dina Muravska - Full-Stack Developer Portfolio

Modern, minimalist, black & neon green developer portfolio website for Dina Muravska, built with **React 19**, **TypeScript**, **Vite**, and **SCSS Modules**.

## 🚀 Features

- **Modern & Premium Design**: Minimal black background (`#080808`), glowing neon green accents (`#22c55e`), glassmorphism cards, and smooth animations.
- **Sticky Navigation**: Adaptive header with scroll detection, active section highlights, social links, and quick CV view/download.
- **Hero & Interactive Terminal**: Live code preview, terminal tabs (`dina.ts`, `skills.json`, `contact.sh`), status badge, and key statistics.
- **About Me**: Professional summary, soft skills, language proficiencies (English Pre-Intermediate A2, Ukrainian Native), and developer philosophy.
- **Skills Showcase**: Categorized tech stack (Languages, Frameworks, Tools, Markup/Styling, Soft Skills) with interactive category filters.
- **Featured Projects**: Comprehensive cards for _Tasteorama_, _Travel-Trucks_, _NoteHub_, _CoffeeVibes_, and _ArtistsHub_ complete with live demo links, repository URLs, detailed role breakdown, and interactive modal view.
- **Experience**: Detailed breakdown of sales & management background (Investagro-Ukraine LLC) demonstrating client relations, task prioritization, and smooth transition to software engineering.
- **Education & Certifications**: Academic degree from Kyiv National University of Technologies and Design, GoIT IT School diploma, Google AI Certificate, and Claude AI certificates.
- **Interactive Contact Form**: Direct copy-to-clipboard buttons for email and phone, instant feedback toasts, and links to Telegram, LinkedIn, and GitHub.
- **Responsive & Mobile-First**: Crafted with SCSS Modules, CSS variables, and flex/grid layouts.

## 🧰 Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite 6
- **Language**: TypeScript 5
- **Styling**: SCSS Modules (`.module.scss`)
- **Icons**: Lucide React
- **Animations**: Motion (Framer Motion)

## 🛠️ Development Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
